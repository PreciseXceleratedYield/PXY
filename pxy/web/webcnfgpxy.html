Manage syscnfgpxy.py

Edit only declared runtime settings. Choice fields use validated dropdowns; computed settings are shown read-only.

Settings are written to the central Python config with a timestamped backup. Invalid settings are rejected before replacement. Changing RUNEXACPXY_RISK_MODE saves the selected mode and its derived activation settings, but does not change a running engine; restart the engine deliberately to apply them.
